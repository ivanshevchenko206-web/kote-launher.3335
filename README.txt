Kote Client: лаунчер + мод (Fabric 1.21.11).
1) Загрузи ВСЁ содержимое этого архива в новый репозиторий на GitHub.
2) Вкладка Actions -> дождись трёх зелёных галочек.
3) Скачай артефакт KoteClient: внутри KoteLauncher.exe и папка mods с модом.
4) Запусти KoteLauncher.exe. В игре меню на правый Shift, зум на C.
